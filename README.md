# 个人主页

这是一个无构建步骤的静态主页，直接打开 `index.html` 即可预览。发布文件为 `index.html`、`style.css`、`script.js`、`favicon.svg` 和 `.nojekyll`。页面没有第三方依赖，也不包含手机号。

## GitHub Pages

将这些文件放入公开仓库 `Steven-31415926.github.io` 的根目录，在仓库 Settings → Pages 中选择 **Deploy from a branch**，来源选 `main` / `(root)`。发布后地址为 `https://steven-31415926.github.io/`。使用自有域名时，还需要在 Pages 设置中配置域名和相应 DNS 记录。
